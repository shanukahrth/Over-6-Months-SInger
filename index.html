Connect to GitHub

One-time setup for this device

This dashboard reads and writes Inventory.xlsx, ShowroomTracker.xlsx and a small overlay file directly in your GitHub repository, so everyone always sees the latest data. Enter the repo details below. Your token is stored only in this browser (localStorage) — it is never sent anywhere except api.github.com.

How do I get a token?
  1. On GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Resource owner: your org/user. Repository access: Only select repositories → pick this repo.
  3. Permissions: Contents → Read and write. Nothing else is required.
  4. Generate, copy the token, and paste it above. Each teammate who needs to save changes should set up their own token on their own device.
